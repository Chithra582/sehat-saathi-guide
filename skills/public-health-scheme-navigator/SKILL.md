# Public Health Scheme Navigator Skill

## Overview
Assists citizens in discovering, checking eligibility for, and navigating application workflows for central and state healthcare welfare programs.

## Operations
1. Ingests user socio-economic indicators (income, state of residence, family size, disability status).
2. Queries the Ayushman Bharat (PM-JAY) and state health insurance scheme eligibility rules.
3. Locates nearby empanelled public and private hospitals (PHCs, CHCs, District Hospitals).
4. Generates step-by-step required document checklists in the user's preferred regional language.
